# ⚡ CreatorKit — The Free Open-Source Toolkit for Creators

A 100% free, private, client-side web application packed with 6 essential tools for short-form video creators, writers, and digital influencers. 

Built with zero external frameworks, zero trackers, and zero API keys.

---

## 🛠️ Included Tools

1. **🎯 Multi-Platform Safe Zone Inspector** — Test 9:16 vertical video framing against TikTok, Instagram Reels, and YouTube Shorts UI overlays.
2. **⏱️ Script Teleprompter & Pacer** — Calculate exact read time by WPM, flag overtime text, and run an in-browser teleprompter with mirror support.
3. **✂️ Thread & Post Splitter** — Break long-form copy into numbered posts for X (280 chars) and Threads (500 chars), with a LinkedIn "...see more" cutoff preview.
4. **📺 YouTube Feed & Truncation Tester** — Simulate mobile and desktop YouTube feeds to ensure titles don't get cut off.
5. **💰 Sponsorship Rate & Pitch Generator** — Calculate fair market brand rates based on views, niche CPMs, and usage rights, with a one-click pitch email generator.
6. **🔗 Self-Hosted Link-in-Bio Builder** — Design a clean link landing page and export a single-file HTML page ready for free hosting.
